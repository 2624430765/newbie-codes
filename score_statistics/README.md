# 📊 学生成绩统计器

> 一个帮老师/家长统计学生成绩的小工具，Python 新手练习项目。

## 难度

⭐⭐（进阶）

## 这个程序能做什么？

录入一堆学生的姓名和分数，然后自动帮你算出：

- 📋 每个学生的成绩和评级（优秀 / 良好 / 及格 / 不及格）
- 📊 平均分、最高分、最低分
- ✅ 及格人数和及格率
- 🏆 按分数从高到低的排名

## 运行方法

1. 电脑上装好 Python（3.6 以上都行）
2. 打开终端，进入这个文件夹（`score_statistics`）
3. 输入命令运行：

```bash
python3 main.py
```

## 使用示例

```
请输入学生名字(输入'完成'结束录入): 小明
请输入 小明 的分数(0-100): 95
✅ 已录入 小明：95 分

请输入学生名字(输入'完成'结束录入): 小红
请输入 小红 的分数(0-100): 58
✅ 已录入 小红：58 分

请输入学生名字(输入'完成'结束录入): 完成
（后面会自动打出成绩明细和统计结果）
```

## 这个项目能学到什么？

| 知识点 | 说明 |
|--------|------|
| 列表 list | 用一个列表装下所有学生，每个学生又是一个字典 |
| 字典 dict | 用字典同时存"名字"和"分数"两样东西 |
| while 循环 | 不停地录入学生，直到输入"完成"才停 |
| if-elif 判断 | 根据分数给每个学生评等级 |
| try/except | 防止输分数时手滑输入了字母导致程序崩溃 |
| sum / max / min | 内置函数，快速求和、找最大值、找最小值 |
| sorted 排序 | 按分数从高到低排出名次 |
| f-string | `f"..."` 花括号里直接放变量，拼接文字超方便 |
| 列表推导式 | 一行代码把分数单独抽出来，新手的进阶写法 |
